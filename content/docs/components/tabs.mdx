## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs";

<Tabs variant="subtle" defaultValue="overview">
  <TabsList aria-label="Project">
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="activity">Activity</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">Overview content</TabsContent>
  <TabsContent value="activity">Activity content</TabsContent>
</Tabs>;
```

## API Reference

`variant`: default (segmented) or subtle. Root accepts Base UI `value`, `defaultValue`, `onValueChange`, and `orientation`. Triggers support `disabled`. The shared indicator follows selection; fluid hover follows the pointer. SizeProvider controls density. Base UI manages keyboard activation and panel relationships. Reduced motion removes the indicator travel.
