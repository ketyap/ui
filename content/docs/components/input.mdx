## Usage

```tsx
import { Input } from "@/components/ui/input";

<Input aria-label="Email" type="email" placeholder="you@example.com" />;
```

## API Reference

`value` / `defaultValue`, `onChange`, `onValueChange`, `disabled`, `readOnly`, `required`, `type` and native input attributes follow Base UI Input. `density`: default or compact, inherited from SizeProvider when omitted. `shape`: rounded or pill, inherited from ShapeProvider. Native `size` remains the character-width attribute. Use a label or `aria-label`; descriptions and validation messages can be connected through Base UI Field. For prefixes, suffixes and addons, use [InputGroup](/docs/components/input-group).
