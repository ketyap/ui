## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion";

<Accordion multiple defaultValue={["about"]}>
  <AccordionItem value="about">
    <AccordionTrigger>About</AccordionTrigger>
    <AccordionContent>Details about this project.</AccordionContent>
  </AccordionItem>
</Accordion>;
```

## API Reference

Root accepts Base UI Accordion props including `multiple`, `value`, `defaultValue`, `onValueChange` and `disabled`. Values are arrays, including single-panel mode. Items accept `value` and `disabled`. Trigger density follows SizeProvider; height animation respects reduced motion. Use arrow keys, Home/End, Enter and Space.
