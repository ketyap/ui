## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Tooltip,
  TooltipProvider,
  TooltipTrigger,
  TooltipContent,
} from "@/components/ui/tooltip";

<TooltipProvider delay={200}>
  <Tooltip>
    <TooltipTrigger render={<Button />}>Save</TooltipTrigger>
    <TooltipContent side="top">Save changes</TooltipContent>
  </Tooltip>
</TooltipProvider>;
```

## API Reference

`Tooltip` accepts Base UI Root props including `disabled`, `open`, `defaultOpen`, and `onOpenChange`. Provider `delay` defaults to 200ms; Trigger `delay` overrides it. Content supports `side`, `align`, `sideOffset` (8px), and the Base UI Popup props. There is no arrow. Reduced motion removes transitions.
