## Usage

```tsx
import {
  Table,
  TableHeader,
  TableBody,
  TableRow,
  TableHead,
  TableCell,
  TableCaption,
} from "@/components/ui/table";

<Table>
  <TableCaption>Reading list</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead>Title</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow selected>
      <TableCell>Dune</TableCell>
    </TableRow>
  </TableBody>
</Table>;
```

## API Reference

All parts accept their native table element props. Table `size`: default or compact, otherwise inherited. Row `selected` adds selection styling; `interactive` enables fluid hover. Put an accessible Button or link inside an interactive row. Table does not invent row keyboard semantics or manage sorting, filtering or pagination. Horizontal overflow remains scrollable.
