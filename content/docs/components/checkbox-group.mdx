## Usage

```tsx
import { CheckboxGroup, CheckboxItem } from "@/components/ui/checkbox-group";

<CheckboxGroup aria-label="Interests" defaultValue={["science"]}>
  <CheckboxItem value="science" label="Science" description="New discoveries" />
  <CheckboxItem value="history" label="History" />
</CheckboxGroup>;
```

## API Reference

Group uses Base UI `value`, `defaultValue` (string arrays), `onValueChange`, `disabled` and form props. Give the group an accessible name. CheckboxItem composes the standalone Checkbox, sharing its check-drawing animation, and accepts Base UI Checkbox Root props and requires `label`; `description` is optional. Both individual and group disabling are supported. Tab moves between checkboxes; Space changes selection. Density follows SizeProvider.
