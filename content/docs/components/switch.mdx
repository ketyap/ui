## Usage

```tsx
import { Switch } from "@/components/ui/switch";

<Switch label="Notifications" defaultChecked />;
```

## API Reference

Accepts Base UI Switch Root props: `checked`, `defaultChecked`, `onCheckedChange`, `disabled`, `name` and `required`. Optional `label` labels the control. Without it provide `aria-label`. `size`: default or compact; otherwise inherits SizeProvider.
