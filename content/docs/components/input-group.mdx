## Usage

```tsx
import { InputGroup, InputField } from "@/components/ui/input-group";

<InputGroup>
  <InputField label="Website" prefix="https://" placeholder="example.com" />
</InputGroup>;
```

## API Reference

InputGroup accepts div props and optional `size` (default or compact). InputField reuses Input and accepts its props plus `label`, `description`, `error`, `prefix`, `suffix`, `addon`, `icon` and `labelHidden`. `onChange` is the standard input event. Base UI Field connects labels, descriptions and errors.
