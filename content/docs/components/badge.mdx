## Usage

```tsx
import { Badge } from "@/components/ui/badge";

<Badge variant="dot" color="green">
  Ready
</Badge>;
```

## API Reference

`variant`: solid or dot. Existing default, secondary, outline and destructive variants remain available. `color`: the demonstrated Tailwind color names. `size`: default or compact (inherited when omitted). `icon`: an SVG component. Shape follows ShapeProvider.
