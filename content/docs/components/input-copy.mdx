## Usage

```tsx
import { InputCopy } from "@/components/ui/input-copy";

<InputCopy value="https://example.com" label="Share link" variant="button" />;
```

## API Reference

`value`: required string. `label`: optional text. `variant`: icon (default) or button. `align`: right (default) or left. `size`: default or compact. `disabled`: disables copying. `onCopy`: called only after a successful copy. Success resets after two seconds. Clipboard failures are announced and can be retried.
