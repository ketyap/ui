## Usage

```tsx
import { RadioGroup, RadioItem } from "@/components/ui/radio-group";

<RadioGroup aria-label="Schedule" defaultValue="weekly">
  <RadioItem value="daily" label="Daily" />
  <RadioItem value="weekly" label="Weekly" description="A weekly summary" />
</RadioGroup>;
```

## API Reference

Group accepts Base UI RadioGroup props: `value`, `defaultValue`, `onValueChange`, `disabled`, `name`. RadioItem requires `value` and `label`, with optional `description` and `disabled`. Base UI owns selection, roving focus and arrow-key navigation. Density follows SizeProvider.
